# Команда агентов ECHO

Роли переписаны и сокращены под этот проект по мотивам агентов из [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) (MIT License, Copyright (c) 2026 Donchitos). Оттуда взяты набор ролей и правила работы с Godot; порядок работы, проверки и запреты — свои, из `CLAUDE.md`.

| Агент | Делает |
| --- | --- |
| `game-designer` | бриф этапа из дизайн-документа: правила, числа, граничные случаи, критерии готовности |
| `gameplay-programmer` | первая версия механики и её проверка в дымовом прогоне |
| `technical-artist` | шейдеры, эффекты, ощущение удара, снимки до и после |
| `ui-programmer` | HUD, меню, экранные кнопки под палец |
| `qa-tester` | поиск ошибок после этапа, новые проверки в `tests/smoke.gd` |

Ведущий — главная сессия. Он пишет бриф, выдаёт каждому агенту отдельное рабочее дерево, проверяет и дорабатывает результат, коммитит.
