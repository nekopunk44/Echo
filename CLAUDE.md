# ECHO — правила проекта

Мобильный roguelike-survivor в стиле VHS на Godot 4.7 (GDScript), сначала Android. Портрет 720×1280, рендер Compatibility. Дизайн-документ лежит вне репозитория: `C:\Users\Admin\Desktop\ECHO — дизайн-документ.md`.

## Как устроена работа

Работа идёт этапами. Ведущий — главная сессия Claude Code. Он ставит задачу агентам команды (`.claude/agents/`), проверяет их работу, дорабатывает её, коммитит и отправляет.

- Агент работает в выданном ему рабочем дереве (`git worktree`, обычно `C:\Users\Admin\Desktop\echo-wt\<задача>`) и только там.
- Агент **не коммитит и не пушит**, не трогает `.github/`, `export_presets.cfg`, `ci/`, не скачивает файлы, не ставит плагины и аддоны. Если без этого не обойтись, он пишет об этом в отчёте.
- Если бриф неоднозначен, агент выбирает разумный вариант по дизайн-документу и отмечает его в отчёте. Работу ради вопроса агент не останавливает.
- В конце агент пишет отчёт:
  1. что сделано;
  2. изменённые файлы;
  3. какие проверки прогнаны и с каким результатом;
  4. решения, принятые без брифа;
  5. риски и что ведущему посмотреть глазами.

## Карта кода

Сцены почти не используются: всё собирается из кода в `main.gd` через `preload` (константы `XxxScript`). Дочерние узлы обращаются к главной сцене через нетипизированное поле `main`.

| Файл | Что внутри |
| --- | --- |
| `main.gd` | цикл дублей и состояния (`State`), спавн врагов, опыт и выбор плёнок, всё оружие (`tick_weapons`, `_fire_*`) |
| `player.gd`, `ghost.gd`, `enemy.gd` | герой (стик и WASD), копия прошлого дубля, враги (`kind` 0–6, 6 — босс Цензор) |
| `recorder.gd` | автозагрузка `Recorder`: путь и выборы текущего дубля, последние 5 дублей для копий |
| `upgrades.gd`, `weapons.gd`, `loadout.gd` | каталог оружия и плёнок (данные), параметры оружия по уровням, сборка игрока |
| `hud.gd`, `levelup_ui.gd`, `run_menu.gd` | HUD (слой 2), выбор плёнки (слой 10), меню и экран победы (слой 20) |
| `vhs.gd`, `vhs.gdshader` | VHS-пост-эффект (слой 1, между ареной и HUD): `pulse()`, `slow`, `rewind_hold`, `flash_rewind()` |
| `juice.gd` | Camera2D: тряска, хитстоп. **Единственное место, где меняется `Engine.time_scale`** |
| `backdrop.gd` | пол арены под жанр, `z_index = -10` |
| `art.gd` | палитра (`PINK`, `CYAN`, `YELLOW`, `DARK`, `WHITE`), шрифты (`OSD_FONT`, `BOLD_FONT`), процедурные силуэты |
| `debug_keys.gd` | отладочные клавиши, только в отладочной сборке |
| `tests/smoke.gd` | дымовой прогон для CI |
| `tests/shots.gd` | снимки экрана для проверки внешнего вида |

Группы узлов: `enemies`, `bullets`, `ghosts`, `fx`, `pickups`.

## Стиль

- Табы; `gdformat --line-length 120`; `gdlint` по `.gdlintrc`: не больше 1000 строк в файле, 6 `return` в функции, 20 публичных методов. Порядок в файле: `extends`, `##`-описание, сигналы, enum, константы, переменные, функции.
- Комментарии и тексты интерфейса — по-русски. Комментарий объясняет «почему», а не пересказывает код. У файла есть `##`-описание сверху.
- Цвета берутся из `art.gd`, шрифты — `Art.OSD_FONT` (надписи плеера: REC, PAUSE, цифры) и `Art.BOLD_FONT` (заголовки, кнопки). Основной текст по умолчанию набран Exo 2.
- Числа баланса — константы в начале файла или данные в `upgrades.gd`/`weapons.gd`, а не россыпь в коде.
- У новых скриптов и шейдеров Godot создаёт `.uid` — их нужно сохранить рядом.

## Ловушки

- `TextureRect`: `expand_mode` и `stretch_mode` задавать **до** `size` и `texture`, иначе размер упирается в исходник текстуры.
- Касания первым получает `player.gd` (`_input` идёт снизу дерева вверх). Новая экранная кнопка должна отсекаться в `player._input`.
- `--headless` не компилирует шейдеры: шейдер и любой внешний вид проверяются снимками (`tests/shots.tscn`).
- Время: физика идёт 60 тиков в секунду реального времени, `delta` умножается на `time_scale`. `Recorder` пишет позицию на каждый тик.
- Телефон: кнопки не меньше 88 px, текст не мельче 18 px, контраст на тёмном фоне. Сотни врагов на экране — без аллокаций в `_process` и `_physics_process`, где можно обойтись без них.

## Проверки

Перед отчётом прогнать то же, что CI (`.github/workflows/ci.yml`). `G` — путь к `Godot_v4.7.2-stable_win64_console.exe` (лежит на рабочем столе).

```bash
gdformat --check --line-length 120 . && gdlint .
"$G" --headless --path . --import
"$G" --headless --fixed-fps 60 --path . res://tests/smoke.tscn   # в выводе: SMOKE OK, без SCRIPT ERROR
"$G" --path . --resolution 720x1280 res://tests/shots.tscn -- <папка для PNG>   # для визуальных правок
```

Новая механика получает проверку в `tests/smoke.gd`.
